# Issue実装計画作成

指定されたGitHubのIssue番号を元に、実装計画を作成し、`.claude/plans/issue-{番号}.md`として保存します。

## 手順

1. **Issue情報の取得**
   - `mcp__github__get_issue`ツールを使って、指定されたIssue番号の詳細を取得
   - リポジトリオーナー: `KishiKyousuke`
   - リポジトリ名: `draft_watcher`

2. **現状分析**
   - 関連するコードファイルを確認
   - 既存の実装を調査
   - 依存関係を把握

3. **実装計画の作成**
   以下の内容を含む簡潔な計画を作成：

   ### 必須セクション
   - **概要**: Issueのタイトルと目的
   - **現状分析**: 現在の実装状況と問題点（簡潔に）
   - **実装計画**: ステップバイステップの実装手順
     - データベース変更が必要な場合はマイグレーションファイル名とカラム追加内容
     - モデル変更（リレーション、バリデーション、メソッド追加など）
     - コントローラー変更（アクション追加、パラメータ変更など）
     - ビュー変更（新規作成、追加要素の説明）
     - その他必要な変更（ルーティング、国際化など）
   - **テスト項目**: 確認すべき動作（チェックリスト形式）
   - **実装時の注意点**: 特に気をつけるべきポイント

4. **ファイル保存**
   - 作成した計画を`.claude/plans/issue-{番号}.md`に保存
   - マークダウン形式で整形

5. **確認**
   - 保存したファイルパスをユーザーに報告
   - 計画の概要を簡潔に説明

## 注意事項

- **コード例は書かない** - ファイル名、変更内容、追加要素の説明のみ
- 実装手順は「何を」「どのファイルで」変更するかを明記
- CLAUDE.mdのプロジェクト情報を参考にする
- 既存の実装パターンに従う

## 使用例

```
/plan-issue 14
```

このコマンドで Issue #14 の実装計画が作成され、`.claude/plans/issue-14.md`に保存されます。
