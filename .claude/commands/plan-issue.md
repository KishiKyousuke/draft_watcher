# Issue実装計画作成

指定されたGitHubのIssue番号を元に、詳細な設計・実装計画を作成し、`.claude/plans/issue-{番号}.md`として保存します。

## 手順

1. **Issue情報の取得**
   - `mcp__github__get_issue`ツールを使って、指定されたIssue番号の詳細を取得
   - リポジトリオーナー: `KishiKyousuke`
   - リポジトリ名: `draft_watcher`

2. **現状分析**
   - 関連するコードファイルを確認
   - 既存の実装を調査
   - 依存関係を把握

3. **実装計画の作成**
   以下の内容を含む詳細な計画を作成：

   ### 必須セクション
   - **概要**: Issueのタイトルと目的
   - **現状分析**: 現在の実装状況と問題点
   - **実装計画**: ステップバイステップの実装手順
     - バックエンド変更（モデル、コントローラー、マイグレーション等）
     - フロントエンド変更（ビュー、JavaScript等）
     - ルーティング変更
   - **技術的な詳細**: 各ステップの具体的な実装コード例
   - **テスト項目**: 確認すべき動作
   - **関連Issue**: 紐づくIssueやPR

4. **ファイル保存**
   - 作成した計画を`.claude/plans/issue-{番号}.md`に保存
   - マークダウン形式で整形

5. **確認**
   - 保存したファイルパスをユーザーに報告
   - 計画の概要を簡潔に説明

## 注意事項

- 計画は具体的で実装可能なレベルまで詳細化する
- コード例は実際のプロジェクト構造に合わせる
- CLAUDE.mdのプロジェクト情報を参考にする
- 既存の実装パターンに従う

## 使用例

```
/plan-issue 14
```

このコマンドで Issue #14 の実装計画が作成され、`.claude/plans/issue-14.md`に保存されます。
