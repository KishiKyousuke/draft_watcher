# test-issue コマンド

指定されたIssue番号に対応する実装の動作確認をPlaywrightMCPを使って行います。

## 使い方

```
/test-issue 14
```

## タスク

1. `.claude/plans/issue-{番号}.md`ファイルを読み込む
2. 実装計画から確認すべき項目を抽出する
3. PlaywrightMCPを使ってブラウザで以下を実行:
   - 実装された機能が正しく動作するか確認
   - 画面遷移が正しいか確認
   - データが正しく表示・保存されるか確認
   - エラーハンドリングが適切か確認
4. 確認結果をまとめてユーザーに報告

## 注意事項

- Railsサーバーが起動していることを確認してから実行
- ブラウザが既に起動している場合はエラーになる可能性があるため、その場合は再試行
- テストデータが必要な場合は事前に作成する
- 確認が完了したらブラウザを閉じる

---

あなたは引数として渡されたIssue番号: {{args}}

このIssue番号に対応する`.claude/plans/issue-{{args}}.md`を読み込み、実装内容を理解してください。

次に、PlaywrightMCPを使って以下の手順で動作確認を行ってください:

1. **テストデータの確認**: 必要なデータ（Draft、Teamなど）が存在するか確認し、なければ作成
2. **機能テスト**: 実装計画に記載された機能を実際に操作して確認
3. **結果報告**: 各確認項目について✓/✗で結果を報告

確認後は必ずブラウザを閉じてください。
