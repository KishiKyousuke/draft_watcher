# Issue #14: ドラフト詳細から指名作成を行えるようにする

## 概要

**タイトル**: [機能] ドラフト詳細から指名作成を行えるようにする

**目的**: ドラフト会議では特定の順番で各球団が指名を行うため、ドラフト詳細画面から球団を起点として指名を登録できるようにし、リアルタイム入力をスムーズにする。

## 現状分析

### 既存の実装
- `Draft`モデル: ドラフト会議を管理（年度、先攻リーグ、バーチャルフラグ）
- `Pick`モデル: 指名結果を管理（選手、球団、年度、指名順位など）
- `TeamStanding`モデル: ドラフトごとのチーム順位を記録

### 問題点
1. `Pick`と`Draft`が直接関連付けられていない（draft_idカラムが存在しない）
2. ドラフト詳細画面に指名追加ボタンがない
3. ドラフト詳細画面に各球団の指名結果が表示されていない
4. 指名作成フォームにドラフト選択機能がない

## 実装計画

### 1. データベース変更

**マイグレーション1**: `db/migrate/YYYYMMDDHHMMSS_add_draft_id_to_picks.rb`
- `picks`テーブルに`draft_id`カラムを追加（外部キー、NOT NULL制約）
- 既存データがある場合は`year`を元に`draft_id`を設定する処理を追加

**マイグレーション2**: `db/migrate/YYYYMMDDHHMMSS_remove_year_from_picks.rb`
- `picks`テーブルから`year`カラムを削除（draft経由で取得可能なため不要）

### 2. モデル変更

**`app/models/pick.rb`**:
- `belongs_to :draft`を追加
- `draft_id`のバリデーションを追加
- `player_id`のユニーク制約のscopeを`year`から`draft_id`に変更
- `year`バリデーションを削除（カラム自体を削除するため）
- `year`メソッドを定義して`draft.year`を返すようにする（ビューでの互換性のため）

**`app/models/draft.rb`**:
- `has_many :picks, dependent: :destroy`を追加
- `picks_by_team(team)`メソッド: 特定球団の指名を取得
- `next_draft_round_for_team(team)`メソッド: 次の指名順位を自動計算

### 3. コントローラー変更

**`app/controllers/drafts_controller.rb`**:
- `show`アクション: `@picks_by_team`を追加（球団ごとの指名をN+1対策して取得）

**`app/controllers/picks_controller.rb`**:
- `new`アクション:
  - `draft_id`パラメータを受け取り`@draft`を設定
  - `team_id`パラメータを受け取り、指名順位を自動計算
  - `@drafts`を全件取得（ドラフト選択セレクトボックス用）
- `create`アクション:
  - 作成後、draft_idがある場合はドラフト詳細画面にリダイレクト
- `edit`アクション:
  - `@draft`と`@drafts`を設定
- `update`アクション:
  - 更新後、draft_idがある場合はドラフト詳細画面にリダイレクト
- `destroy`アクション:
  - 削除後、draft_idがあった場合はドラフト詳細画面にリダイレクト
- `pick_params`:
  - `:draft_id`を許可パラメータに追加
  - `:year`を許可パラメータから削除（カラム自体を削除するため）

### 4. ビュー変更

**`app/views/drafts/show.html.erb`**:
- 既存のチーム順位テーブルを各球団セクションに変更
- 各球団セクションに「指名追加」ボタンを追加（`new_pick_path(draft_id: @draft.id, team_id: standing.team.id)`へのリンク）
- 各球団セクションに指名結果リストを表示
  - 指名順位、選手名、ステータスバッジ（育成、抽選待ち、完全終了）
  - 編集・削除ボタン

**`app/views/picks/new.html.erb`**:
- 選手検索フィールドの後に「ドラフト選択」セレクトボックスを追加
- `year`フィールドを削除（draft経由で取得するため不要）
- キャンセルボタンのリンク先を条件分岐（`@draft`がある場合はドラフト詳細へ）

**`app/views/picks/edit.html.erb`**:
- `new.html.erb`と同様に「ドラフト選択」セレクトボックスを追加
- `year`フィールドを削除（draft経由で取得するため不要）
- キャンセルボタンのリンク先を条件分岐

### 5. 国際化ファイル

**`config/locales/ja.yml`**:
- `activerecord.attributes.pick.draft: ドラフト`を追加

### 6. ルーティング

変更不要（既存のRESTfulルートをそのまま使用）

## 実装時の注意点

1. **既存データの扱い**: 既存のPickデータがある場合、`year`を元に`draft_id`を設定してから`year`カラムを削除
2. **yearメソッドの追加**: `year`カラムを削除した後も`pick.year`が使えるよう、モデルに`delegate :year, to: :draft`または`def year; draft.year; end`を定義
3. **N+1問題対策**: ドラフト詳細画面で`includes`を使用して指名データを事前読み込み
4. **指名順位の計算ロジック**: 1位未確定、育成指名、完全終了フラグを考慮
5. **リダイレクト先の分岐**: ドラフト詳細から作成/編集/削除した場合はドラフト詳細に戻る
