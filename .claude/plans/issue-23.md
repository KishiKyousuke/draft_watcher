# Issue #23: 選手一覧の改善

## 概要

選手一覧の使い勝手を良くするための微修正を加える

## 現状分析

### 現在の実装状況
- 選手一覧画面（`players/index`）には「新規選手登録」「指名結果一覧」「CSVエクスポート」「CSVインポート」のリンクがある
- 指名結果には全ての指名（仮想ドラフト、未確定を含む）が表示されている
- ドラフト一覧画面（`drafts/index`）には選手一覧へのリンクがない
- 本番ドラフト未指名選手でのフィルタリング機能がない

### 問題点
1. 選手一覧とドラフト一覧を相互に行き来できない
2. 指名結果に仮想ドラフトや未確定の指名が含まれており、確定した指名のみを見たい場合に分かりにくい
3. 本番ドラフトで未指名の選手だけを絞り込めない

## 実装計画

### 1. ビュー変更

#### `app/views/players/index.html.erb`
- ヘッダー部分の既存ボタンに「ドラフト一覧」ボタンを追加
- 検索フォームに「未指名のみ」チェックボックスを追加

#### `app/views/drafts/index.html.erb`
- ヘッダー部分に「選手一覧」ボタンを追加

### 2. コントローラー変更

#### `app/controllers/players_controller.rb`
- `index`アクション内で指名結果のフィルタリングを変更
  - `player.picks`を直接参照している箇所を修正
  - 仮想ドラフト（`draft.virtual == true`）の指名を除外
  - 未確定の指名（`confirmed == false`）を除外
- 「未指名のみ」パラメータがある場合、本番ドラフトで確定した指名がない選手のみを表示

### 3. モデル変更（任意）

#### `app/models/player.rb`
- `confirmed_picks`メソッドを追加：本番ドラフトの確定した指名のみを返すスコープまたはメソッド
- `drafted_in_official?`メソッドを追加：本番ドラフトで指名されているかを判定

### 4. 国際化

#### `config/locales/ja.yml`
- 「ドラフト一覧」ボタンのラベル追加
- 「未指名のみ」チェックボックスのラベル追加

## テスト項目

- [ ] 選手一覧画面に「ドラフト一覧」ボタンが表示される
- [ ] 「ドラフト一覧」ボタンをクリックするとドラフト一覧画面に遷移する
- [ ] ドラフト一覧画面に「選手一覧」ボタンが表示される
- [ ] 「選手一覧」ボタンをクリックすると選手一覧画面に遷移する
- [ ] 選手一覧の指名結果に仮想ドラフトの指名が表示されない
- [ ] 選手一覧の指名結果に未確定の指名が表示されない
- [ ] 本番ドラフトで確定した指名のみが表示される
- [ ] 「未指名のみ」チェックボックスが検索フォームに表示される
- [ ] 「未指名のみ」をチェックして検索すると、本番ドラフトで指名されていない選手のみが表示される
- [ ] 「未指名のみ」チェックを外すと全選手が表示される
- [ ] 他の検索条件（名前、カテゴリ、ポジション）と組み合わせて使用できる

## 実装時の注意点

1. **N+1クエリの回避**
   - `includes(:picks)`を使用して指名結果を効率的に取得
   - さらに`includes(picks: :draft)`で仮想/本番の判定に必要なデータも一緒に取得

2. **指名結果の表示ロジック**
   - ビューで`player.picks.each`している箇所を、フィルタリング済みのメソッド呼び出しに変更
   - 例: `player.confirmed_picks.each`

3. **未指名判定**
   - 「未指名」とは「本番ドラフトで確定した指名が存在しない」という意味
   - 仮想ドラフトでの指名や未確定の指名は「未指名」として扱う

4. **UI/UX**
   - 「ドラフト一覧」ボタンは既存のボタンと同じスタイルで配置
   - 「未指名のみ」チェックボックスは検索フォーム内に追加

5. **後方互換性**
   - 既存の検索機能を壊さないように注意
   - パラメータがない場合は従来通りの動作を維持
